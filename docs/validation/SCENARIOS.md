# Attack scenario library

_Generated by `npm run docs:scenarios` from `src/lib/validation/library`. Do not edit by hand._

28 versioned, immutable scenarios. Every one runs against the real authorization gateway with mock integrations in a throwaway sandbox tenant. Taxonomy references are to OWASP (LLM Top 10 2025, Agentic AI Threats T1-T15) and MITRE ATLAS identifiers, and are given only where the mapping is accurate; they are labels, not a compliance claim.

## Weakened variants

A variant deliberately switches one control off or leaves one argument unpinned so you can see what that control contributes. A variant that lets an attack through is a _finding_, not a bug in the lab: it is how remediation proposals and regression tests are demonstrated.
